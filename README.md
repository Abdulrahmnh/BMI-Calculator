## Source & setup

The Flutter entry point is [`lib/main.dart`](lib/main.dart); dependencies and SDK requirements are in [`pubspec.yaml`](pubspec.yaml). To explore locally, use a compatible Flutter/Dart environment, run `flutter pub get`, then `flutter run` with an appropriate device or emulator.

> Educational calculator only; not a medical tool. The original Dart SDK constraint is 2.15.x–2.x. The original implementation is preserved; the project has not been rebuilt or retested during this documentation update.
